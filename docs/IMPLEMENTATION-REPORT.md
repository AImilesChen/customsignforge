# 开发阶段交付记录 · 2026-10-18

本次交付为可在本地 Cloudflare Workers 环境运行的功能版本，沿用已确认的 UI、品牌标志和页面文案。旧设计原型 4173 保留；正式工程为 website，预览端口 4321。未公开部署。

## 已实现

- 首页、六类产品及详情、作品列表与详情、关于、合作采购、定制流程、询价、两类广告落地页、六份政策页面、404。
- 服务端输出正文、页面标题、描述、canonical 与社交分享图；预览禁止索引。未发布内容返回404。
- 询价校验、蜜罐、限流、幂等保存、咨询编号和摘要；不收集访客密码或强制注册。WhatsApp 空配置时不提供假链接。
- 中文后台：产品/作品/部分编辑页、草稿与发布分离、SEO与排序、宣传图片、联系方式和FAQ、询价筛选与人工跟进历史。并发保存校验版本。
- Google OIDC 与邮箱一次性验证码服务端流程、管理员白名单、可撤销会话、CSRF与同源检查。本机开发入口单独限制在本地环境。
- 图片 JPEG/PNG/WebP 上传限制、来源备注、替代文字和发布引用控制；未发布上传图不向访客公开。现有生成图继续标注为概念图。
- 本地数据库迁移、幂等种子数据、随机密钥初始化、启动和检查脚本、操作文档。

## 验证证据

1. `npm test`：7项通过，包括登录约束、询价幂等、草稿隔离、权限、跟进与图片发布控制。
2. `npm run check`：无类型错误；`npm run build`构建通过。
3. `npm run test:live`：9项实际本地Workers/D1检查通过，包括退出后旧会话失效、草稿不影响公开页、发布更新可见。
4. `node scripts/routes-smoke.mjs`：21个互相链接的公开页面、11个图片资源返回正常；主要标题与禁止索引检查通过。
5. 浏览器实际完成本机登录、产品管理查看、询价保存、后台详情与跟进保存；演示记录明确标为本地测试。手机390px首页、360px询价和移动菜单已检查；首页320/375/390/768/1024/1440宽度未见横向溢出。这不等于所有实体设备均已验收。

机器记录及截图在 `docs/evidence/`。Google官方账号回调、真实邮件投递与线上Cloudflare未配置，不能计为通过。

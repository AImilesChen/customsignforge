# 询价联系方式与私有图纸（2026-10-19）

用户要求：表单明确留下邮箱；询问有无图纸并可上传；WhatsApp或手机号码必填，以便团队主动跟进。用户明确取消收费短信验证码，因此不接入短信服务、不新增短信密钥或费用；号码仅做格式校验，不标记已验证。

## 用户流程

1. 现有Google/邮箱登录仍必需。表单Contact Email展示只读的已验证账户邮箱；后端从认证会话写入提交时邮箱快照，忽略客户端伪造邮箱和验证标记。
2. 必选WhatsApp或Phone，必填含国际区号的号码。接受空格、括号、短横线及00前缀，保存为+开头的国际格式。只保证字段/格式有效，不能证明号码归属或询价真实性。
3. 必选图纸准备状态：现在上传、暂无需设计帮助、稍后提供。暂无图纸仍能询价；选择现在上传须至少有一个有效文件。
4. 支持PDF/AI/EPS/DWG/DXF/JPG/PNG/WebP；CDR等格式提示导出PDF。最多3个，每个10MiB，合计20MiB。文件有上传/删除/失败重试状态，刷新页面可恢复本账户尚未提交的文件。
5. 保存成功后，附件关联到该询价，客户账户和后台可下载。WhatsApp消息可包含联系邮箱、号码和图纸状态；附件不会自动发送到WhatsApp，点击外部链接也不会自动发送消息。
6. 后台列表可看到号码，WhatsApp渠道可手动打开该号码的聊天入口；号码显示未验证。没有自动添加联系人或发送消息。

## 存储和权限

新增迁移0008_enquiry_files.sql，只新增附件表及索引，不改现有询价字段或历史记录。元数据在D1，二进制存放现有R2的enquiry-files/前缀；文件不会进入公开宣传图库。已用Wrangler只读确认生产桶r2.dev关闭、无自定义公开域名。

上传和删除均需有效客户会话、同源和客户CSRF；用户只能处理自己的待提交文件。下载需要客户本人或管理员身份，强制attachment/octet-stream、no-store、nosniff和sandbox。只返回受控API下载地址，不返回R2密钥。按文件扩展名及内容头检查、限制请求体/数量/总大小并限制频率。文件内容头检查不等于恶意软件扫描，不提供在线解析或预览。

文件上传先预留受限容量，再写R2，失败保留或清除可清理状态。询价插入和附件归属更新同一D1 batch执行；条件插入再次验证所有权、有效期和ready状态，防止并发取消/复用造成错误关联。重复提交保持幂等，历史旧格式的相同请求可重试，但新请求必须填联系号码和图纸状态。

未提交文件24小时后禁止访问，由现有定时维护任务清理。删除中状态先占位，防止删除与关联竞态；失败对象保留清理记录。询价删除会先移除对应R2文件和附件行。已提交文件保留随询价，不在24小时草稿清理中误删。

隐私草案同步增加号码、图纸类别、主动项目跟进、私有存储及草稿期限；原有经营/政策待确认条目继续保留，本次未将草案宣称已获法律批准。
